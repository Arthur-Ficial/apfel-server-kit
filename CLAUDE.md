# apfel-server-kit - Project Instructions

## The Golden Goal

apfel-server-kit is the one shared Swift package that every apfel ecosystem tool depends on to talk to a local `apfel --serve` process - it discovers the `apfel` binary, finds a free port, spawns and health-polls the server, and streams `/v1/chat/completions` over Server-Sent Events, so the five tools (apfel-quick, apfel-chat, apfel-clip, apfel-gui, apfelpilot) stop duplicating ~320 lines of subprocess lifecycle each and a single bug fix propagates everywhere. It IS transport plumbing: `ApfelServer`, `ApfelClient`, `SSEParser`, `ApfelBinaryFinder`, and typed `ApfelServerError`, all Swift 6 strict-concurrency, dependency-free (`URLSession`, `Process`, `Darwin.bind()` only), TDD, and honest about failure. It is NOT an inference engine, an OpenAI type library, or a coupling point - it owns no model output, pulls in neither ApfelCore nor Hummingbird, and talks only to `127.0.0.1`. It versions independently of apfel against apfel's published, semver-protected HTTP surface. Keep it small, stable, and boring - scope creep into model logic, cloud calls, or app-level UI belongs in the consuming tool, never here.
